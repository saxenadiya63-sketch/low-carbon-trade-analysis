# Global Trade in Low Carbon Technology Products (1994–2023)

## Project Overview

This project presents an end-to-end data analytics solution to analyze global trade in low-carbon technology products from 1994 to 2023. The analysis combines Python for data exploration and Power BI for interactive business reporting to identify trade trends, country performance, competitiveness, economic impact, and future trade opportunities.
  
## Business Objective

The objective of this project is to analyze global trade in low-carbon technology products and transform raw trade data into meaningful business insights. The project focuses on understanding long-term trade trends, identifying leading economies, evaluating import and export dependency, measuring comparative advantage, assessing economic impact, and supporting strategic decision-making through interactive business reporting.

## Dataset Information

- **Dataset:** IMF Global Low Carbon Tech Trade & Impact
- **Source:** Kaggle (Created by Pinar Topuz)
- **Time Period:** 1994–2023
- **Records:** 48,367
- **Countries:** 210
- **Indicators:** 11
- **Product Categories:** 5

The dataset contains global trade information for low-carbon technology products across 210 countries over a 30-year period. It includes indicators related to imports, exports, trade balance, comparative advantage, GDP contribution, and other trade metrics used to evaluate global trade performance and sustainability trends.

## Project Workflow

This project follows an end-to-end data analytics workflow to transform raw trade data into meaningful business insights and The interactive Power BI report consists of six business-focused pages, where each page addresses a specific business question, supported by visual analysis, business insights, and strategic recommendations.
